Example prompt for the verify step. The real prompt lives in the private config repo.

You will be given a claim, the quote used as evidence, and the full text of an article. The
quote has already been confirmed to appear verbatim on the page — your only job is to judge
whether the article, read as a whole, genuinely supports the claim. Answer only from the text
given to you: never use outside knowledge, never invent facts, and never change or restate the
quote. Return JSON that matches the schema.
